# Introduction

This chapter covers the basics of what programming is and why we use Python.

## What is Programming?

Programming is the act of writing instructions for a computer to execute. A program is a sequence of statements that the computer processes one at a time.

### Why Python?

Python is a popular language for teaching because:

- **Readable syntax** — code looks close to English
- **Interpreted** — no compilation step, run immediately
- **Large ecosystem** — libraries for almost anything
- **Cross-platform** — runs on Windows, macOS, Linux

## Your First Program

The traditional first program prints a greeting:

```python
print("Hello, World!")
```

When you run this, the output is:

```text
Hello, World!
```

## Comments

Comments are notes in the code that Python ignores. Use `#` for single-line comments:

```python
# This is a comment
print("This runs")  # This is also a comment
```
