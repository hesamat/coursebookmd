# COMP 1510 — Programming Fundamentals

Welcome to COMP 1510. This course introduces the fundamentals of programming using Python. You will learn about variables, control flow, functions, data structures, and problem-solving strategies.

## How to use this coursebook

- Read chapters sequentially using the **prev/next** buttons at the bottom of each page
- Use the **chapter sidebar** on the left to jump to any chapter
- Use the **table of contents** on the right to navigate within a chapter
- Press **Present** or `F` to enter presentation mode for lectures
- Toggle dark mode with the switch in the top bar
